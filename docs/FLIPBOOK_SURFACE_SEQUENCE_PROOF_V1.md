# Flipbook Surface Sequence Proof V1

`RunFlipbookSurfaceDemo` is a finite four-frame CPU/software surface proof. It stages one four-cell RGBA atlas, selects source rectangles at normalized samples `0.00`, `0.25`, `0.50`, and `0.75`, queues each result with `SceneSpriteAdapter::QueueFrame`, presents each frame through the existing hidden SDL surface seam, and writes only the final P6 PPM artifact.

The proof is deliberately frame-local. `FlipbookFrameSelector` owns only the validated sample-to-rectangle calculation. `SceneSpriteAdapter::QueueFrame` reads the actor transform and queues a sprite; it does not store the selected rectangle in `SceneWorld` and does not mutate transform, `RouteIntent`, or `MovementAuthorityGate` state. The demo snapshots the complete actor transform before the sequence and rejects any post-sequence change.

`flipbook_surface_demo_smoke` verifies invalid frame-count rejection, four rendered and presented frames, deterministic four-frame selection, visible output, nonzero frame/sequence hashes, and P6 artifact magic. The executable passes in Release and AddressSanitizer with `detect_leaks=1`, reporting `frames=4`, `selected=4`, `visible=400`, sequence hash `7898515516691923083`, and final-frame hash `11835874581093820931`. The current non-Vulkan broad suites pass 125/125 in both configurations. It is a finite CPU/software proof, not skeletal animation, a GPU renderer, a persistent desktop/game loop, APK evidence, or production readiness.
