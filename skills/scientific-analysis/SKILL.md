# Scientific Engine Analysis
Laboratorium performa FauzanEngine.

## Functions
- **EDA (Exploratory Data Analysis)**: Mencari anomali pada pemrosesan frame.
- **Statistical Profiling**: Menghitung rata-rata beban CPU/GPU secara ilmiah.
- **Performance Benchmarking**: Memberikan grafik perbandingan antar versi engine.
