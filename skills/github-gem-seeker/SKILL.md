# GitHub Gem Seeker

## Core Philosophy
Jangan membuat ulang roda. Cari proyek open source yang sudah diuji ribuan orang. Selesaikan masalah user dulu, baru buatkan skill-nya kemudian.

## Quality Tiers
- **Legendary**: 50k+ stars (FFmpeg, yt-dlp)
- **Excellent**: 10k+ stars (Pake, ArchiveBox)
- **Solid**: 1k+ stars
- **Promising**: <1k stars (Aktif)

## Workflow
1. Identifikasi kebutuhan (misal: "download video").
2. Cari "legendary-tier" tool (yt-dlp).
3. Instal & eksekusi.
4. Beri kredit ke pembuat proyek original.
