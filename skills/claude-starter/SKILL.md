# Claude Starter

A professional-grade starter kit for Claude, optimized for high-performance engineering tasks and maximum token efficiency.

## Core Capabilities

### 1. TOON (Token-Optimized Object Notation)
- **Concept**: A specialized encoding format designed to reduce the verbosity of data structures.
- **Efficiency**: Achieving 30-60% reduction in token count compared to standard JSON or raw Markdown lists.
- **Impact**: Allows for much larger context windows when mapping out complex engine architectures like FauzanEngine.

### 2. High-Performance Tooling
- **Native Zig Support**: Includes optimized logic for Zig-based data processing, ensuring speed and type safety at the system level.
- **Skill Framework**: A modular architecture that allows 40 distinct skills to activate based on the context of the conversation.

### 3. Engineering Domains
- **Systems Architecture**: Deep-dive analysis of memory, threading, and hardware abstraction.
- **Low-Level Dev**: Expertise in C++, Zig, and Rust performance tuning.
- **Data Engineering**: Efficient handling of large-scale assets and datasets.

## Implementation Guide

### Format Rules
When this skill is active, Claude will prioritize **TOON** for internal data representation to maintain maximum conversational memory.

### Activation Logic
This skill acts as a "Master Template." Every session starting with `claude-starter` inherits a set of strict engineering protocols (SOPs) for code quality and documentation.

- **Version**: 1.0.4 (Stable)
- **Token Saver**: Enabled (TOON v2)
