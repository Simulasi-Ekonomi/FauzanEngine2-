# Aries Logic Processor

## Workflow Berpikir
1. **Identifikasi Kategori**: Apakah ini soal Engine (Physics/Memory) atau Game Design (Logic/Grid)?
2. **Buka Referensi**:
   - Untuk Engine: Baca `references/engine_core.md`
   - Untuk Game Design: Baca `references/game_logic.md`
3. **Sintesis Solusi**: Jawab dengan narasi teknis, BUKAN log mentah.

## Aturan Keras
- DILARANG menampilkan log gravitasi 9.8 jika Bos tanya game Puzzle.
- DILARANG menampilkan link QR Code.
- SELALU gunakan data "FauzaMemoryGuard" untuk masalah RAM Android.
