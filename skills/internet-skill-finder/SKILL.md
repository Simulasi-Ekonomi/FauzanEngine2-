# Internet Skill Finder
Cari skill di 7 repositori GitHub (anthropics, vercel, dll).

## Workflow
1. Jalankan fetch_skills.py untuk mencari keyword.
2. Lakukan Deep Dive jika ditemukan skill yang cocok.
3. Import ke FauzanEngine.
