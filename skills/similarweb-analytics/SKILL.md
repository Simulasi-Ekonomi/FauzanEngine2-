# SimilarWeb Analytics

## Core Capabilities
- **Traffic Analysis**: Total visits, unique visitors, dan tren.
- **Engagement**: Bounce rate dan durasi kunjungan.
- **Geographic breakdown**: Breakdown pengunjung berdasarkan negara.

## API Integration Note
Skill ini menggunakan `ApiClient` untuk memanggil data SimilarWeb secara real-time. Sangat berguna untuk benchmarking FauzanEngine terhadap website engine lainnya.
