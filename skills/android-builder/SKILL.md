# Android Builder
Skill ini mengotomatisasi proses Gradle di dalam Termux untuk FauzanEngine.

## Cara Penggunaan
1. Pastikan JDK 17 dan SDK Android sudah terpasang di Termux.
2. Panggil Aries dengan: "Aries, build apk debug".
3. Hasil build akan muncul di folder `/Builds/Android`.
